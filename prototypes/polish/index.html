01选中内容，直接说怎么改

选择一段文字，或者点击一个内容块。页面为目标加上蓝色描边，并在鼠标附近展开评论浮窗。

浮窗保留引用内容，你可以直接输入修改意见。靠近页面边缘时，浮窗自动避让，发送按钮始终可见。

试着选中这句话，告诉我你希望怎么改。

例如：“这段说明再简短一点”，或“浮窗默认再窄一些”。你也可以直接点击整个灰色区域。

02提交后，留一颗小圆球

点击发送，意见直接交给当前会话。发送成功后，浮窗收成内容旁的小圆球，让页面重新回到阅读状态。

继续讨论

点击圆球，查看这条评论的上下文和回复；有补充要求，就在同一个浮窗里继续说。

橙色表示处理中

agent 确认收到后，圆球变为橙色；收到回复后恢复蓝色并显示新回复标记。尚未接收时保持等待状态。

多处修改

不同位置保留各自的圆球和对话。一次只展开一个浮窗，其他评论继续保留。

随时收起

点空白处或按 Esc 收起，输入不会丢失。未发送的草稿用虚线圆球区分。

03你确认了，这一轮才算完成

收到回复时，页面提示你刷新。点击右上角“刷新”，查看最新内容，再打开圆球阅读回复。页面不会在你阅读时突然跳动。

agent 回复 ≠ 修订完成

只有你在浮窗中勾选“完成”，这条评论的圆球才会消失。刷新后也不会重新出现，其他未完成评论不受影响。

04已确认的风格与范围

✓固定简约飞书风格：白底、灰色层级、蓝色操作，评论界面和新生成的 HTML 保持一致。

✓保留已有 HTML：不自动改变现有文件的设计和排版。

✓保留页面内交互：lavish 的选项、单选／多选、输入框和表单提交继续可用。只替换侧边栏会话区，表单操作不触发评论。

✓命令使用 polish：正式版在 Pi agent 中验证；本页先连接当前 Codex 会话确认功能。

✓文字选区 + 内容块：首版不增加任意矩形拖框。
